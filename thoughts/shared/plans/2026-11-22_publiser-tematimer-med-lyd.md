# Publiser undervisningstimene med lyd

Beads `spansk-ungdomsskole-rbec.4.14`.

Bruk gjeldende GitHub Pages-kilde på offentlig main. Flytt undervisningskatalogen, timenes kilder og de 46 kontrollerte lydfilene, utskriftene og den avgrensede gloseinngangen til en isolert gren. Bygg kandidat og kjør vanlige regresjoner. Kontroller at alle lydknapper starter, og at filene fra domenet er byteidentiske med de lokale MP3-ene.

Publiser gjennom den eksisterende GitHub Pages-flyten. Vent på riktig revisjon før nettlesertesten på www.spansk123.no. Ingen andre lokale arbeidsendringer inngår.
