# Inés og Diego i presens

Beads: `spansk-ungdomsskole-0t1l`.

Behold sted, person og tema, men bruk presens, korte setninger og vanlig ordforråd. Tilpass norsk oversettelse, tre spørsmål og forklaringer til hvert nytt manus. Lag et lokalt innlesingsmanus som læreren kan bruke.

Eksisterende lyd inneholder de gamle fortidsmanusene og kan ikke brukes med de nye oppgavene. Sett lydkilde og varighet til null for disse to historiene, vis «Venter på ny lyd» og sperr start også ved direkte funksjonskall. Bevar filene og cache; fremtidige opptak må få nye filnavn slik at gammel cache ikke kan brukes ved en feiltakelse. Ingen lydgenerering eller publisering inngår.

Legg inn regresjoner før implementasjon for presensinnholdet og sperring av gammel lyd, også når den ligger i offline-cache. Bevar avspillings-, offline-, tastatur- og progresjonstestene for de tre tilgjengelige lyttehistoriene og alle diktatene. Kjør bygg, fokuserte tester, full test:all og diff-check. Oppdater README og Beads med behovet for nye opptak.
