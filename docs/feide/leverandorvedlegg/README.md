## Healthchecks: avklart rolle og faktisk oppbevaring

[FAQ](https://healthchecks.io/docs/faq/#dpa) beskriver eget behandlingsansvar for driftskontakt, konto, fakturering og varslingskontakt. Den forbyr bruk av API-et til kunders persondata. Dette støtter avgrensningen til tomme tekniske signaler og tilfeldige run-IDer i den eksisterende jobben. Det er leverandørens rollebeskrivelse; Oversikt må fortsatt kontrollere at faktisk bruk holder denne grensen. Healthchecks føres som teknisk monitor med operatørdata, ikke automatisk som underdatabehandler for elevdata.

[Personvernvilkårene](https://healthchecks.io/privacy/), oppdatert9.11, beskriver roterende pinghistorikk:100siste signaler på gratisplan og1000på Business/BusinessPlus. Dette er en mengdegrense, ikke en fast frist i dager. Leverandørens databasebackup kan beholdes inntil2måneder. Ikke bruk appens foreslåtte30dagers auditfrist som løfte om sletting i Healthchecks. Tjenesten oppgir Tyskland for primærlagring, men personvernvilkårene omfatter også leverandører/tilgang utenfor EØS; Tyskland alene beviser ikke EØS-only for alle operatørdata.
