# Skoleeiers bekreftelse før oppstart

Fyll inn skolens driftsinstruks og før den inn i DBA C/D og aktiveringsprotokollen. Bruk kontaktopplysninger for ansatte med ansvar. Elevopplysninger hører ikke hjemme i skjemaet.

| Bekreft | Fyll inn |
| --- | --- |
| Skoleeier og myndighet | Juridisk navn, org.nr., navn og rolle på den som godkjenner |
| Skole og avtale | Skole, Feide-organisasjon, antall klasser, start- og sluttdato |
| Opphør og sletting | Dato for tilgangsstans, eksportfrist og frist for aktiv sluttsletting. Forslag ved opphør er 30 dager til eksport og aktiv sletting. Bekreft auditfrist på 30 dager og at daglig opprydding velger poster fra 27 dagers alder. |
| Sikker eksport | Autorisert mottaker, hvordan mottakerens identitet bekreftes og godkjent sikker kanal |
| Hendelser og rettighetskrav | Kontakt, stedfortreder, sikker varslingskanal og personvernombud |
| Underlag og godkjenning | Referanse til behandlingsgrunnlag, personvernvurdering og godkjent DBA C/D med dokumenterte kopi- og journalfrister. Navn, rolle og dato for bekreftelsen. |
